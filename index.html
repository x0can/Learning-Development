Program design

How I build a learning program

Every program I build follows the same pathway. I start from what learners must be able to do, then design the modules, activities and assessments that get them there. I keep improving the program from learner results and feedback.

Step 1

Objectives

Define what each learner must be able to do by the end.

Step 2

Modules

Structure the content into a clear, progressive sequence.

Step 3

Activities

Hands-on labs, real scenarios and practice that build skills.

Step 4

Assessment

Quizzes and rubrics in Canvas LMS and Formstack to measure progress.
